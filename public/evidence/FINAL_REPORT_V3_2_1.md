# 可折叠 3D 打印机｜V3.2.1 最终验收纠错报告

## 1. 纠错摘要

本补丁严格针对 V3.2 验收指出的三项问题进行定向修复（不修改 `0.800` 筛选门槛，不修改历史版本原始结果）：
1. **P0-1 连续碰撞上界修复**：废除从离散采样点推断运动上界的 `_motion_upper_bound()`，改用解析/运动学认证接口 `BoundedTrajectory`（`StaticTrajectory`、`LipschitzTrajectory`、`IntervalBoundTrajectory`）。缺少可信上界的任意 `Callable` 强制返回 `UNRESOLVED`，绝不静默返回 `PASS`。
2. **P0-2 GitHub 同步脚本防误删**：移除 `prepare_sync.py` 中的 `shutil.rmtree()` 与 `git checkout -B`，改为基于 `manifest.json` 的逐文件非破坏式安全合并。
3. **P1 F09 筛选一致性修复**：核实 `F09 (lift=85.0)` 收纳比 `0.802 > 0.800` 确属未通过整体筛选；通过将 `lift_mm` 真实几何调整为 `82.0 mm` 并重新建模验证，在不修改 `0.800` 门槛的前提下使 `F09_L82` 收纳比降至 `0.786 <= 0.800`。
