# 全方案仿真实验过程复盘

日期：2026-11-14
分支：`feature/full-mechanism-simulation`
关键提交：`6142192`、`390c30e`、`1d6f399`
最终结果：F07、F12 为稳健推荐；SCZ 为探索型第三项；F08 为工程备选。

> 这是一份实验过程记录，不是实机验证报告。几何筛选是 L1，静力学/误差是 L2，唯一的三维有限元只覆盖等效悬臂梁，不能代表整机、铰链或打印精度。

## 1. 起点与问题定义

仓库已有案例、文献、技术规划和二维根部翻折演示，但没有冻结实机、没有完整的 F01–F14 参数表，也没有统一的可执行模型。最初的 `data/virtual_validation_parameters.csv` 多数为“待测量”。

因此第一步不是直接选方案，而是建立一个可被代码复核的共同问题：

- 工作空间目标：180 mm 打印高度；
- 参考外形：347×315×365 mm 的 A1 mini 启发外形；
- 收纳包络：必须包含运输附件，非箱体方案加入料盘/电源/工具包络；
- 硬约束：无穿透、可达、工作空间、系统收纳比 ≤0.800；
- 机构差异：根部翻折、横臂、伸缩、槽轨、外部托架、箱体、抽屉和剪刀分别实例化；
- 未知尺寸：明确写成假设，不冒充实测。

这一阶段的产物是 `config/candidates.json`、统一状态轨迹和评价契约。

## 2. 第一轮：统一初筛与过早的推荐

第一轮为 15 套候选建立 31 姿态模型，运行 Shapely 相交、包络体积、降阶梁/锁点刚度、10,000 次误差抽样和 NSGA-II。

第一轮结果中名义通过的是 F07、F08、F11、F12、F14、SCZ；初始权重选择一度给出 **F07 + F04**。当时 F04 名义轨迹有少量穿透，但优化器在一个抽象“抬升 + 平移 + 转轴”路径中找到了无穿透解。

这个结果后来被证明不够可靠。问题不在随机数，而在模型命名与模型实际内容不一致：F04 被称为槽轨机构，却没有槽轨实体、滚轮或导向约束。

## 3. 独立审阅与返工

独立代码审阅提出并核实了以下问题：

1. F04/F10 只有抽象枢轴路径，没有真实槽轨；
2. 误差与挠度目标在优化变量变化时可能是常数；
3. 非剪刀方案的驱动力统一除以 50 mm，跨机构不可比；
4. F11 没有运动箱盖，F14 没有第二阶段翻转；
5. 31 姿态只能证明采样点无穿透，不是连续扫掠；
6. 优化约束漏掉装配可达性；
7. 跨机构刚度仍是启发式；
8. “最小不可行解”没有真正保存。

处理方式与结果：

| 问题 | 修复 | 结果影响 |
|---|---|---|
| F04 槽轨未实例化 | 增加槽轨中心线、槽宽、滚轮和导向间隙；槽轨与热床参与碰撞 | F04 名义穿透 45.338 mm²，优化无可行解，撤回推荐 |
| 目标退化 | 臂长、伸缩重叠、槽宽进入误差/刚度 | F02 长短臂和 F12 重叠量现在产生不同目标值 |
| 驱动力不可比 | 翻折、伸缩、抽屉、剪刀分别建模 | F12 得到 39.7 N 重力/摩擦驱动，而不是 0 N |
| F11/F14 联动缺失 | F11 增加箱盖，F14 增加双柱预筛与第二阶段翻转 | F11/F14 名义失败，保留失败证据 |
| 采样不足 | 名义 201/501/1001；候选优化解最高 5001 | 所有名义状态稳定；F07/F08/F12/SCZ 5001 姿态均无穿透 |
| 可达性遗漏 | 优化加入第 5 个可达性约束，选择阶段检查 `passed_screen` | 不再依赖驱动力无穷大间接排除不可达解 |
| 最小不可行缺失 | 保存 `least_infeasible`、最大/最小约束违反度 | F04 等失败方案仍有证据可查 |

完整审阅原文与逐项处置见 `reviews/independent_review_round1.md`。

## 4. 返工后的最终筛选

返工后的名义通过者为 F07、F08、F12、SCZ。NSGA-II 有可行解的候选同样只有这四个；F04 的旧优化解在新槽轨碰撞模型下失效。

最终权重扰动 100 次的结果：

| 候选 | 前三频率 | 基线分数（越低越好） | 候选间 Pareto |
|---|---:|---:|---|
| F07 | 100% | 0.1670 | 是 |
| F08 | 100% | 0.2544 | 否 |
| F12 | 100% | 0.4666 | 是 |
| SCZ | 0% | 0.7346 | 是 |

选择规则在优化前就冻结：只推荐前三频率 ≥80% 且来自不同机构族的方案。F08 与 F07 同属根部翻折，且在候选间 Pareto 中被支配，因此不与 F07 重复推荐。没有为了凑满三套而降低门槛。

## 5. 为什么推荐 F07 和 F12

### F07：单立柱抬升根部翻折

- 优化参数：抬升 80 mm；
- 系统收纳比 0.4927；
- 降阶挠度 0.319 mm；
- 重复定位 P95 0.559 mm（20,000 次）；
- 峰值力矩 4,061 N·mm，按声明 50 mm 力臂换算 81.2 N；
- 概念增量成本 320 CNY；
- 1001 与 5001 姿态均无穿透。

选择理由：在几何、误差、成本和机构复杂度上同时处于前沿，且 100 次权重扰动中始终进入前三。它仍是根部铰链，但推荐来自结果，不是预设偏好。

### F12：三级伸缩立柱

- 优化参数：重叠 65.3 mm；
- 系统收纳比 **0.7998**；
- 降阶挠度 0.171 mm；
- 重复定位 P95 0.658 mm（20,000 次）；
- 峰值驱动 39.7 N（重力 + 0.08 摩擦 / 0.8 效率）；
- 概念增量成本 610 CNY；
- 1001 与 5001 姿态均无穿透。

选择理由：提供与根部翻折不同的机构族，降阶刚度最好，权重扰动前三频率 100%。但收纳比距离 0.800 门槛不足 0.005，是边界候选；附件包络或重叠量的小变化可能改变结论。

## 6. 第三项与材料准备

第三项不能用“再选一个通过概率高的”来定义，否则只会重复 F07。

- 按**工程通过概率**：F08 更强，5001 姿态通过、前三频率 100%、成本 337 CNY；
- 按**独立机构证据增益**：SCZ 更强，属于独立剪刀升降机构，但前三频率 0%，P95 0.893 mm、成本 850 CNY。

本阶段选择 **SCZ 作为探索型第三项，F08 作为工程备选**。这是一个有条件的决策：若 SCZ 在空载/低载荷台架出现卡滞、低位扭矩超限或回差无法收敛，就停止并转 F08，而不是继续用软件补偿掩盖机械问题。

材料准备遵循“先试片、后台架、最后整机”：

- 48 项清单见 `verification/third_option_bom.csv`；
- SCZ 样机概念估算 1,538–3,020 CNY；
- F08 备选 870–1,650 CNY；
- 共用计量/安全装备 1,770–4,700 CNY；
- 全部为 ±40% 概念估算，不是供应商报价；
- 在 SCZ 闸门评审前，不采购 F08 的 CNC 铰链。

具体见 `verification/THIRD_OPTION_DECISION.md` 与 `verification/PHYSICAL_VALIDATION_PLAN.md`。

## 7. 补充验证的证据等级

- **名义 201/501/1001**：15 套的通过/失败状态稳定；
- **优化候选 201/501/1001/2001/5001**：F07/F08/F12/SCZ 均通过，最大穿透 0 mm²；
- **局部 L3 FEA**：I=7000 mm⁴ 等效悬臂梁，20/40/80/160 单元；最细 12,075 DOF，与 Euler–Bernoulli 差 2.4%；
- **单位与符号**：SymPy 剪刀导数与有限差分一致，Pint 力矩/刚度量纲通过；
- **回归测试**：30 项；
- **交付检查**：138/138 通过；
- **未完成**：连续扫掠证明、整机/铰链 FEA、多体动力学、寿命、热变形和实机恢复打印。

5001 个离散姿态仍不是连续扫掠证明；这里只报告“采样密度稳定”，不报告“连续轨迹已证明”。

## 8. 失败与限制记录

- 完整 Git 历史包下载过慢，改用浅层稀疏克隆；
- PyBullet 需要本机没有的 MSVC，未安装，因此没有多体动力学结论；
- CalculiX/FreeCAD 不在 PATH，改用 build123d/OpenCascade 和 scikit-fem 局部梁验证；
- 云端盘 `.venv` 复制过慢且中断造成 uv 缓存损坏，改用本机 uv 隔离环境；
- build123d 扫描到损坏系统字体，使用仓库内只读字体过滤，不修改系统文件；
- F08 CAD 的跨度检查误把带负坐标的包络当作坐标上限，已改为 `max-min` 检查并重导出；
- 第二轮独立审阅因执行模型周配额中断，AGY 复核进程亦超时，均未作为完成证据；
- 当前仍无实机测量、真实材料参数、轴承间隙、热变形和寿命数据。

这些错误都保留在 `../task_plan.md` 和 `notes.md`，不删除失败版本。

## 9. 复现与下一步

从仓库根目录：

```bash
bash simulation/run_all.sh
```

该命令会重新运行 27 项测试、全方案初筛、误差抽样、NSGA-II、敏感性分析、高密度复验、梁 FEA、图表/动画、概念 CAD、环境记录、报告与 136 项交付检查。

下一步不应再增加未标定仿真，而应执行实物 P0–P6：

1. 冻结原机与全部接口；
2. 制作 SCZ 关节试片，测孔轴配合；
3. 空载 20 次全行程；
4. 1/2/5 kg 分级静载与 10 N 端部侧载；
5. 30 N 锁紧滑移和 200 次锁紧衰减；
6. 20 次展开的 16 点重复定位；
7. 最低工作高度扭矩、双向回差与非线性 Z 映射；
8. 同一 G-code 原机/折叠机各三次打印对照。

只有通过这些闸门，才能把“推荐进入实测”升级为“实机可行”。
