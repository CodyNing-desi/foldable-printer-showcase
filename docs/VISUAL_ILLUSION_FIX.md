# 显示层"疑似穿模"观感优化（2026-11-18）

前提：穿模专项审计已证明冻结版几何全链路 0 穿透（见 PENETRATION_AUDIT.md）。本轮只改**显示与标注**，不改任何机构几何、变换或透明度掩盖逻辑；改后复跑视觉验收与 e2e 确认无回归。

## 逐项：观感来源 → 优化 → 证据

| # | 容易被看成穿模的观感 | 根因（显示层） | 优化 | 对照截图 |
|---|---|---|---|---|
| 1 | X 光模式下零件"互相穿过" | 半透明实体叠加，深度关系丢失 | X 光改为**幽灵参考**：非焦点零件填充 opacity 0.05、仅保留 0.55 轮廓线；焦点/运动件保持实体 | illusion-before/xray → illusion-after/xray |
| 2 | 关节处"有个球埋进金属里" | 3D 标记球（r=3.4mm）嵌入零件内部 | 标记改**屏幕空间环点+标签**（Html），不再有任何嵌入实体的辅助几何 | markers-labels 前后 |
| 3 | 销"融化"进孔里、看不出间隙 | 名义接触间隙 0.3–0.4mm 小于像素，剪影融合 | 新增**琥珀色配合间隙环**（绕销轴名义接触面，仅标注开启时显示），明示"这里有设计间隙"；环为标注几何非零件 | markers-labels / foldend 前后 |
| 4 | 左右立柱/双剪叉臂融成一团 | 同族同色多实例剪影无区分 | 同族多实例**明度区分**（左/右 ±0.05–0.07 HSL），剪影可分离 | scz-cross / foldend 前后 |
| 5 | 虚线轨迹"穿过"零件 | 轨迹线参与深度测试，被金属遮挡/穿插 | 轨迹改**标注层**（depthTest=false、renderOrder 999、opacity 0.55），读作叠加注释而非几何 | foldend 前后 |
| 6 | 折叠末段臂"贴进"底座/热床 | 设计间隙小于一个像素 | 播放器常驻说明："贴近≠穿透：配合间隙 0.3–0.4mm，全行程审计 0 穿透"；末段画面配合间隙环可见 | foldend 前后 |
| 7 | 相机 zoom 进入实体内部看到内壁 | minDistance 30 允许穿入 | minDistance 提升到 80，防止相机进入固体 | — |
| 8 | 地面圆盘边缘"切过"底座 | 地面盘半径 320 过大、不透明 | 半径 240、opacity 0.7，弱化为参考地平面 | foldend 前后 |

## 不变项（防止"用显示掩盖真实干涉"）

- 机构几何、轨道、爆炸向量、隔离逻辑均未改；历史版本回放的**真实干涉仍红色高亮+体积/归因提示**，不被本轮优化隐藏。
- X 光/幽灵模式只改变非焦点零件的呈现，焦点与运动件始终实体；干涉高亮优先级高于幽灵化。
- 配合间隙环与关节环点均为标注层，审计脚本不将其计入零件集合。
