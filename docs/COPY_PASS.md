# 文案与可读性整改（2026-11-17，第三轮补充）

目标：让**没参与项目的人**不看内部目录也能读懂；把"内部依据"降为二级元信息，关键解释提升到可读字号。事实与数字一律不变。

## 原则

1. **先人话，后口径**：每个场景的主文案用日常语言讲清"发生了什么、为什么重要"；版本号、文件路径、算法名只出现在证据层。
2. **术语首次出现即解释**：收纳比、穿透面积、名义/优化/工程入围、连续碰撞认证、挠度/P95、运动副、缩比 1:2、齐套——首页新增"术语速览"展开层，章节内首次出现处带括号解释。
3. **证据文件配"人话摘要"**：每份证据新增 `plain` 一句（它是什么、证明了什么），在证据索引与候选抽屉中以 16.5px 显示；原始路径降为 13px 等宽元信息。
4. **小字只留纯元信息**：帧号、t 值、文件路径、分支名保留 13–14px；凡承担解释职责的文字 ≥16px，画面说明 20px，章节导语 25px。
5. **内部代号翻译**：`L2b 闭合+孔轴审计` → "装配约束闭合检查 + 孔位真实存在性审计"；`回差` → "换向空程"；`|dH/dS|` → "水平推 1 毫米只升约 0.15 毫米"；`2.5D 口径` → "平面投影口径"。

## 示例（Before → After）

- 阶段说明：`V3 扫掠+附件 · simulation_v3/` → "把行李也算进体积：收纳不能只算机器本体，料盘、电源、工具都要一起带走。算上附件后 F07 一度出局，F12 改了结构又回来。"
- 证据条目：`simulation/reviews/independent_review_round1.md` → "外部独立审查逐条检查模型代码后写的问题清单：F04 的'槽轨'当时只是一条抽象路径，并没有真实机构。"（路径仍在下方小字）
- 运动风险：`低位 |dH/dS|=6.771：推力放大` → "越低越费力（低位水平推 1 毫米只升约 0.15 毫米）；换向空程与左右同步只能靠实物测"
- 制造状态：`PETG 数量不足 · 缺口盘点中` → "PETG（一种更韧、耐反复拆装的打印材料）零件不够；具体缺多少待'齐套'核查（逐件点数确认到齐）后回填"
- 自动演示字幕：全部 14 段重写为观众语言（如"第一轮统一考试：6 套及格。F04 在一个简化过头的模型里'假及格'，一度被推荐。"）
